### About

I'm Chris — systems engineer from Denmark. My primary domain is Rust: low-level systems programming, performance-critical backends, CLI tooling, and security-focused design. Node.js and TypeScript sit close behind — I've shipped production backends in both and I work across the full stack when the project calls for it.

Security research runs alongside everything I build. A few years in pen testing changes how you think about software — you stop asking *does this work* and start asking *how does this break*. That mindset shows up in architecture decisions, attack surface thinking, and how I handle trust boundaries.

Deep into crypto infrastructure too: Bitcoin, Monero, Solana, DeFi — not as a user, but at the protocol and backend layer. I run LLMs locally and pull them into real workflows and tooling. Linux and networking are my daily environment, and I care about what my software actually runs on — DNS, encryption, compilers, the full picture.

Open to senior roles, contracts, and meaningful collaborations. If it's real and worth building, I'm interested.
